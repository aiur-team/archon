Archon hosted publishing

A private home for a single self-contained HTML document.

Publishing is not available yet

This deployment is a service shell. Publishing, sign-in and document reading are not enabled here, so nothing you send to it will be stored and no document can be opened from it.

You are not signed in, and this page cannot sign you in. Nothing on this page has read, verified or recorded any identity.

What this service will do

When it opens, an Archon agent will be able to ask you to publish one HTML document it has already built on your machine. You approve that request in this browser, signed in to GitHub, and the document is then readable only by you. Approval always happens here, in a page you navigated to yourself — never inside the agent, and never inside the document.

In the meantime

Documents built by Archon are self-contained HTML files. You can open one directly from your own filesystem without this service, and without sending it anywhere.
